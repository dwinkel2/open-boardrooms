# AGENTS.md — Kill Board

When the user asks to "run the kill board," decide whether a venture should continue, or points you at a filled-in `course-context-template.md`, run the Kill Board.

- The board definition lives in `killboard/SKILL.md` (skill) or `killboard.md` (prompt). Follow it exactly.
- It attacks the founder's own case for continuing across three rounds with five fixed advisors (Annie Duke, Eric Ries, Paul Graham, Jerry Colonna, Seth Godin) plus 2-3 per-case seats (the Walked-Away Founder, the Customer Who Left, optionally the Next-Bet Advocate). The verdict is DOUBLE DOWN, PIVOT, or KILL, always with dated kill criteria.
- Run the advisors ONE AT A TIME (this runtime is sequential, not parallel). Same rounds, same deliverables, just longer.
- Write the five deliverables (continue-case.md, decision-memo.md, changelog.md, board-report.md, kill-board-dashboard.html) to a working folder the user names first.
- Never invent facts the founder didn't give. Mark every guess GUESS; a milestone with no date gets NO DATE. The verdict lands on the venture, never on the person.
