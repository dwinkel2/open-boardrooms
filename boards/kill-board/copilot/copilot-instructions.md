# Copilot Instructions — Kill Board

When the user asks to "run the kill board" or decide whether a venture should continue, run the prompt in `.github/prompts/killboard.prompt.md`.

- It attacks the founder's own case for continuing across three rounds with five fixed advisors (Annie Duke, Eric Ries, Paul Graham, Jerry Colonna, Seth Godin) plus 2-3 per-case seats. The verdict is DOUBLE DOWN, PIVOT, or KILL, always with dated kill criteria.
- Run the advisors ONE AT A TIME (sequential). Same rounds and deliverables as the parallel version, just longer.
- Produce the five deliverables (continue-case.md, decision-memo.md, changelog.md, board-report.md, kill-board-dashboard.html) in a working folder the user names first.
- Never invent facts. Mark every guess GUESS; a milestone with no date gets NO DATE. The verdict lands on the venture, never on the person.
