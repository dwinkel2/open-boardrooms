# Setup: AI Policy Boardroom for Google Antigravity (Gemini)

Google retired the Gemini CLI for individual plans in June 2026 and moved everyone to Antigravity, its free agentic app. Use Antigravity. The board runs the seats one at a time.

## Before you start

1. Create a folder in your home directory called `ai-policy-boardroom`.
2. Optional: fill in `course-context-template.md` from this pack and save it inside that folder as `course-context.md`.

## Install

1. Download Google Antigravity from antigravity.google/download and install it. Sign in with your Google account.
2. Copy `aipolicyboard.md` from this pack into `~/.gemini/antigravity/global_workflows/`. On a Mac, press Cmd+Shift+Period in Finder to see the hidden `.gemini` folder. Create the path if it doesn't exist.
3. Copy this pack's `GEMINI.md` to `~/.gemini/GEMINI.md`. If you already have one, paste the contents at the end of it.
4. Open your `ai-policy-boardroom` folder in Antigravity.
5. In the Agent panel, type `/aipolicyboard`, paste your policy, and answer the intake. Approve the file writes.

Antigravity is still in preview. If `/aipolicyboard` doesn't appear, check antigravity.google/docs for the current workflows path and move the file there.

## What happens when it runs

Ten seats, one after another, three rounds, then the rebuild and a second pass. Expect twenty to forty minutes. Read the changelog first when it's done.

## If something breaks

The workflow isn't listed: the path moved. Check the docs link above.
It stops mid-round: type "continue with the next seat." Each seat's file is saved as it goes.
