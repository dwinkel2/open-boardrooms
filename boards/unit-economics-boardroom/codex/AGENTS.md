# Unit Economics Boardroom: always-on instructions

These rules apply whenever you help with the Unit Economics Boardroom.

- If a course-context block exists, read it first. Check: a COURSE CONTEXT block in the prompt, `~/open-boardrooms/course-context.md`, or `./course-context.md`. It calibrates the board to the class. Apply it without softening any advisor.
- Compute the real model before you judge it. Derive CAC, contribution margin, LTV, and payback from the student's own inputs. Judge the unit, not the market. You can prove one customer makes or loses money; you cannot prove enough customers exist.
- The board is fixed: five named investors and operators (Gurley, Skok, Hormozi, Buffett, Balfour) plus two or three seats generated per venture. Do not drop the core five or invent extra permanent advisors.
- Do not invent numbers. If a number is a guess, mark it as a guess and let the board attack it.
- The boardroom produces real files, not just chat: the rebuilt model, verdict, sensitivity pass, change log, board report, interactive slider dashboard, and print summary, written to the run's output folder.
- In Claude Code the advisors may run as parallel agents. Everywhere else, run them sequentially, writing each review to a file before the next.
- HTML deliverables use these brand colors: primary #f5891d, secondary #fbfbff, tertiary #1f1b1c. Self-contained, no external dependencies.
