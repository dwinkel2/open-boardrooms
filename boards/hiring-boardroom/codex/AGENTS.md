# AGENTS.md — Hiring Board

When the user asks to "run the hiring board," review a next hire, or points you at a filled-in `course-context-template.md`, run the Hiring Boardroom board.

- The board definition lives in `hiringboard/SKILL.md` (skill) or `hiringboard.md` (prompt). Follow it exactly.
- It reviews the user's NEXT HIRE and org design across three rounds with five fixed advisors (Geoff Smart, Claire Hughes Johnson, Ben Horowitz, Keith Rabois, Jason Fried) plus 2-3 per-case seats.
- Review the advisors ONE AT A TIME (this runtime is sequential, not parallel). Same rounds, same deliverables, just longer.
- Write the five deliverables (hiring-decision.md, scorecard.md, changelog.md, board-summary.md, hiring-dashboard.html) to a working folder the user names first.
- Never invent facts the founder didn't give. Where a scorecard outcome needs a real number, write the structure and flag the gap.
