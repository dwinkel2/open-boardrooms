# Copilot Instructions — Hiring Board

When the user asks to "run the hiring board" or review a next hire, run the prompt in `.github/prompts/hiringboard.prompt.md`.

- It reviews the user's NEXT HIRE and org design across three rounds with five fixed advisors (Geoff Smart, Claire Hughes Johnson, Ben Horowitz, Keith Rabois, Jason Fried) plus 2-3 per-case seats.
- Review the advisors ONE AT A TIME (sequential). Same rounds and deliverables as the parallel version, just longer.
- Produce the five deliverables (hiring-decision.md, scorecard.md, changelog.md, board-summary.md, hiring-dashboard.html) in a working folder the user names first.
- Never invent facts. Flag any scorecard number the founder must supply.
