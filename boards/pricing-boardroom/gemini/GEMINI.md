# GEMINI.md: Pricing Boardroom

When the user types `/pricingboard`, asks to "run the pricing board," asks whether their price is right, or points you at a price and a filled-in `course-context.md`, run the Pricing Boardroom workflow in `pricingboard.md`.

- Follow the workflow exactly: every step, every persona block, every format.
- It runs a founder's Price Sheet through three rounds with five fixed advisors (Madhavan Ramanujam, Patrick Campbell, Jason Cohen, William Poundstone, Jeff Bezos) plus 2 to 3 seats built for the venture (the Paying Buyer, the Category Pricer, and an optional specialist). It ends with three numbers: the floor, the ask, and the test price, plus the unit the price is per.
- Run the advisors ONE AT A TIME. This runtime is sequential, not parallel. Same rounds, same deliverables, just longer. Save each advisor's file before starting the next.
- Write every file to `~/pricing-boardroom/[venture-unit]/`: `price-sheet.md`, the `round-1/`, `round-2/`, `round-3/` folders, `price-sheet-rebuilt.md`, `changelog.md`, `board-report.md`, and `pricing-dashboard.html`. Read `~/open-boardrooms/course-context.md` first if it exists.
- Never invent a number. Where the founder wrote GUESS or UNKNOWN, say what to measure and how. An UNKNOWN in the arithmetic is a finding by itself.
- Founder-facing files (the rebuilt sheet, the changelog, the board report, the final synthesis) are plain English, second person, short paragraphs. No em-dashes, no bold for emphasis, no hype, no "it's not X, it's Y" reframes, and none of these words: delve, leverage, journey, navigate, unlock, tailored, elevate, seamless, robust, empower.
- Mode B, The Price Conversation, runs only when the founder asks for it, after Mode A. Play the buyer, stop and wait for the founder's typed line, and rule each one LANDS, SHAKY, or CAVED.
