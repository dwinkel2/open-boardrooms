# Contributing

Three kinds of contribution are welcome. Fixes to an advisor, ports to another tool, and new boards.

## Fix an advisor

Every claim about a real person in an `advisors/` profile needs a source. If you find one that is wrong, unsourced, or out of date, open an issue with the correction and a link, or send a pull request that edits the profile and its source list. Reconstructed quotes must be flagged as reconstructed. Do not add biographical facts you cannot source.

## Port a board

Seven boards ship Codex, Gemini/Antigravity, and Copilot folders. The other seven do not. A port is the Claude Code command translated for that tool's runtime: same rounds, same deliverables, advisors reviewed one at a time instead of in parallel. Include a one-page SETUP.md written for a non-technical teacher on a possibly IT-locked laptop. Copy the layout of an existing port folder.

## Propose a board

Open an issue first. A board proposal has eight parts:

1. The artifact under review. One concrete thing a person brings.
2. The failure-mode map. The four to six distinct ways that artifact dies. Each becomes one fixed advisor's territory.
3. The verdict vocabulary. A three-level overall scale and a three-level component scale, in the domain's own words.
4. The baseline. The structured version of the artifact the board attacks, with its template.
5. The intake. Mandatory fields and optional high-value fields.
6. The fixed seats, with a one-paragraph case for each and the fight lines between them.
7. The dynamic seats. Two or three roles generated per case.
8. The three deliverables and the exit condition.

A board ships in two forms or it does not ship: the Claude Code command (plus its skill) and the paste-into-any-chat setup sheet. The setup sheet is the one most people will use, so it is not an afterthought.

## House rules

- No invented facts about real people. Source it or flag it.
- Advisors speak in their own voice, not a committee's. Keep them adversarial.
- Every instruction must be runnable by a teacher with zero prep. Test each step by asking whether someone could actually do it as written.
- Plain English. No hype about AI or any tool.
